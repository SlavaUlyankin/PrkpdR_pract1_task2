# WebAR: трекинг изображения (MindAR + A-Frame)

## Структура проекта

```
webar-marker/
├── index.html          ← готовая AR-страница
├── targets.mind         ← ВАЖНО: этого файла пока нет, его нужно сгенерировать (см. ниже)
├── models/
│   └── ceramic_vase.glb ← 3D-модель, уже добавлена
└── README.md
```

## Как получить targets.mind

1. Откройте официальный онлайн-компилятор MindAR:
   **https://hiukim.github.io/mind-ar-js-doc/tools/compile/**
2. Загрузите фотографию, которую будете использовать как маркер
   (требования — см. в основном ответе Claude).
3. Дождитесь обработки — компилятор покажет карту распознанных
   особенностей (жёлтые точки) поверх изображения.
4. Нажмите «Download Compiled» и сохраните файл именно под именем
   `targets.mind` в корень этой папки, рядом с `index.html`.

## Как запустить локально

Нельзя просто открыть `index.html` двойным кликом (`file://`) —
браузер заблокирует доступ к камере. Нужен локальный сервер:

```bash
cd webar-marker
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере.
